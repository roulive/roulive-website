Playing with Adobe Lightroom

29 juin 2008
Photo

I've played with Adobe Lightroom this morning.

It's an impressive tool. But you need some good hardware. I did try it a year ago on my PC which was too slow to run it nicely. Now that I got my new Mac Pro, it works fine, even if some of the tools aren't real time yet. I'm running Mac Pro with 4GB RAM, 2 Quad Core 2,8 Ghz and it's not real time. Crazy, huh?

I first tried Aperture but, I think it doesn't stand the comparison with Lightroom. It is still slow, and even if the interface is quite nice, it's not that user-friendly.

I still have a lot of trouble getting the right configuration for Lighroom in terms of: Automatic photo importation, Export settings, Web Publishing. I will try to post in this later.
